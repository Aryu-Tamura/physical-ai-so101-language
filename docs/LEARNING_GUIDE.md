# 朝の確認：自分で説明できるようにする（15〜30分）

1. 最終動画を見て、言語理解・物体情報・制御・物理演算の担当を区別する。
2. `demo.py --instruction "青ではなく赤を左に置いて" --video` を実行。認識した対象と実際に運ばれた対象を見る。
3. `--scenario duplicate` で赤が2つある場面を試す。なぜ動かないことが正しいのか説明する。
4. `--offset .035 --retry --video` を追加して、位置誤差からの再試行を見る。再観測で正しい位置が得られる前提の弱さを説明する。
5. データの1行を読む：`outputs/evaluation/trials.json`。期待結果、LLM出力、判定、最終座標がどう違うか確認する。
6. 自分で新しい指示を3つ作って試す。公開済み評価と混ぜず、追加実験として結果を保存する。
