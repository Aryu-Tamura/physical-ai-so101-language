# 実機への移行メモ（提出レポート・動画とは別資料）

## 何を引き継げるか
日本語→構造化指示、対象の一意性確認、実行状態、ログ形式、評価用指示は共通化できる。MuJoCoの関節角度や制御ゲインを実機へそのまま送れるという意味ではない。

## 段階
1. SO-101 follower、電源、USB接続、固定具と軽い対象物を準備。テキスト指示+幾何制御だけならleaderは必須ではない。模倣学習用の実演収集をする段階でleader等を検討する。
2. 公式LeRobotの手順でモータ設定、組み立て、関節校正、低速単関節テスト。物理的に電源を切れる状態で、机へ固定し、人の手が作業域にない状態で開始。
3. 実機・シミュレータ間の関節名、正負、単位、ゼロ点、制限値を一つずつ対応付ける。角度制御の応答、重力によるずれ、バックラッシュを測る。
4. 真上の固定カメラを導入。最初は色付きブロックと既知サイズ、平面のマーカーで対象座標を得る。カメラ座標→机→アーム基準座標を校正する。今回のシミュレータ内部座標取得を、この観測器へ交換する。
5. まずグリッパを開いた状態で目標の上へ移動し、接触なしで位置誤差を測る。次に軽量ブロック一つの把持を試す。力・速度・高さの上限を実測に合わせる。
6. 持ち上がったかは実画像または別センサから判定する。現在の「真の物体高さ」は実機では読めないので、見失った場合を含め判定器を評価する。
7. 同じ指示・配置の評価セットを再実行し、音声やVLA追加の前に、実機で増えた失敗と遅延を集計する。

## 今回まだ再現していない差
モータの発熱・速度制限・バックラッシュ、実際の摩擦と把持力、USB遅延、カメラの遮蔽・照明・推定誤差、位置誤差が次の観測でも残る状況。今回は実機性能を保証しない。
